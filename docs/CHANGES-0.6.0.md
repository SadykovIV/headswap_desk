# HeadSwap Desktop 0.6.0

Локальная сборка для ручной проверки. На GitHub не опубликована.

- Добавлено беспроводное подключение CarLife для совместимых магнитол.
- Сопряжение `headswap-desk` через код в уведомлении, короткая первоначальная настройка, настройка батареи и установка компонентов.
- Двойное «Назад» возвращает домой; добавлены управление шайбой и вызов доступного голосового входа Яндекса.
- Динамическая частота кадров и выбор верхнего битрейта в Мбит/с. Исправлены очереди и временные метки звука и видео.
- Добавлены шторка уведомлений, настройка автоматического воспроизведения и передача доступной обложки текущего трека.
- Улучшена независимость экрана магнитолы от блокировки телефона на поддерживающих её прошивках.
- Обновлён адаптированный DriveDeck до 0.6.9 code332, сохранены модификации HeadSwap. Добавлен CarBridge с отдельной проверкой издателя и обновлений.
- Новая иконка, изображения на экранах настройки и ожидания, оформление уведомлений.

## Перед ручной проверкой

Установите APK поверх текущих приложений и повторно активируйте HeadSwap. Порядок действий — в [инструкции](../INSTALL.md), сценарии — в [проверке 0.6.0](TESTING-0.6.0.md).

Независимость от боковой кнопки блокировки недоступна на проверенном AOSP Android 17; используйте гашение панели HeadSwap. Голосовой запуск зависит от экспортируемого входа установленного приложения Яндекса. Микрофон автомобиля этим способом не подключается. Беспроводной CarLife, отображение обложек и итоговая синхронизация на штатном ГУ требуют проверки на автомобиле.
