# Настройки блоками — 0.6.0

Последнее решение пользователя от 9 ноября заменяет ранее выбранные вложенные разделы. Настройки находятся на одном прокручиваемом экране. Ключи и сохранённые значения не меняются; исключение по доступности — временно отключённая шторка уведомлений на ГУ.

| Блок | Содержимое |
|---|---|
| Параметры изображения | Разрешение и свой размер, DPI и свой DPI, битрейт и своя скорость, исправление DPI приложений; управление дисплеем телефона, способ гашения и таймер |
| Звук | Передача звука в CarLife, автоматическое продолжение музыки, состояние доступа |
| Уведомления на магнитоле | Неактивный переключатель и сообщение о временном отключении |
| Приборная панель и HUD | Подсказки, настройка уведомлений навигатора, переход к доступу HeadSwap, пояснения музыки |
| Разрешения приложения | Кнопка открытия единственной вложенной страницы разрешений и общий статус |
| Компоненты HeadSwap Desktop | Установка и обновление компонентов; DriveDeck и CarBridge показаны подряд, без переключателя компонента |
| Обслуживание | Повтор первоначальной настройки и отправка журнала |

На странице разрешений зелёная галочка означает выданный доступ, красный крестик — отсутствующий. Значки дополняются текстом и доступным описанием состояния. Нажатие строки открывает реальный системный запрос либо активацию; значок сам разрешение не переключает. Состояние обновляется после возврата. Разрешение поверх приложений сохранено в списке, но не требуется для отключённой шторки.

После завершённой первоначальной настройки «Выдать права приложению» открывает только активацию: Wi-Fi с вводом кода в приложении/уведомлении, команды для компьютера либо доступный выбранному профилю способ. Кнопки первоначальной настройки и установки компонентов в этом блоке больше не появляются. Повтор мастера доступен отдельной кнопкой в настройках.

Способ и таймер гашения остаются видны с сохранёнными значениями даже при выключенном управлении дисплеем. На главном экране сохранены подключение, профиль и тип соединения. «Назад» из разрешений возвращает к прежней позиции блоков, следующий «Назад» — к главному экрану. Пересоздание Activity сохраняет страницу и прокрутку.

Шторка выключена на уровне модели, overlay, gateway и capability компонентов; старое сохранённое `true` её не открывает. Уведомления активации на телефоне, listener подсказок HUD и сведения о музыке продолжают работать. DriveDeck333 получает отсутствие capability и не перехватывает нажатие для шторки.

Проверки обновлённого поведения фиксируются в [TESTING-0.6.0.md](TESTING-0.6.0.md) с фактической сборкой. Предыдущая матрица разделов остаётся историей, а не проверкой нового экрана.
