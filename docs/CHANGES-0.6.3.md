# HeadSwap Desktop 0.6.3

Изменения с версии 0.6.0:

- **Проще активация и восстановление.** Wi-Fi, Shizuku и компьютер собраны на одном экране. Добавлена подготовка восстановления рабочего стола после переподключения USB без внешней Wi-Fi-сети на Android 17 — с отдельным согласием при активации.
- **Улучшен отклик касаний.** В Android Desktop и DriveDeck объединяются устаревающие движения, чтобы они не накапливались в очереди.
- **Понятнее первый запуск.** Последовательные шаги: компоненты → разрешения → активация. При чистой установке выбран DriveDeck, с предложением установить нужный компонент.
- **Удобнее Wi-Fi-сопряжение.** Код можно сразу ввести в приложении или уведомлении; оба способа относятся к одной попытке. Улучшены поиск порта и повторная активация с сохранённым сопряжением.
- **Обновлены меню и статусы.** Активация перенесена в настройки; на главном экране видны версии приложения и компонентов. Кнопки подключения отражают состояние сеанса, исправлен ложный статус «Рабочий стол не готов», убрана лишняя постоянная кнопка ADB.
- **DriveDeck обновлён до сборки 334.** Добавлен отдельный экран его разрешений для названия трека и обложки музыкального виджета.
- **Управление дисплеем телефона выключено по умолчанию.** При обновлении сохраняется ваш прежний выбор.

**После обновления повторно активируйте HeadSwap.** Удалять приложения и настройки не нужно. Для музыкального виджета разрешите доступ к уведомлениям именно DriveDeck · HeadSwap.

В релизе — оба APK, инструкция для Android 13+, команды активации для Windows и macOS и патчи DriveDeck. [Установка и активация](https://github.com/SadykovIV/headswap_desk/blob/v0.6.3/INSTALL.md).
