# Проверка профилей HeadSwap Desktop 0.5.0-dev

Версия для разработки — Android 13+, код 38. HeadSwap устанавливается поверх 0.4.1 с сохранением настроек. Для CarBridge нужен отдельный APK профиля. Обычный CarBridge Offline v0.43 запускается как самостоятельная программа и не объявляет вход SDK. Для локальной проверки разработан отдельный адаптер интерфейса v0.43. У него свои пакет и подпись.

## На телефоне

1. Установите основной APK HeadSwap. Обновление останавливает старый процесс, поэтому снова активируйте доступ обычным способом.
2. Установите совместимый APK профиля. Остановите соединение с ГУ. На **главном экране HeadSwap** откройте **«Профиль» → «CarBridge»**. Если установлено несколько адаптеров, выберите точный пакет и проверьте сертификат издателя. Для локального адаптера на основе v0.43 пакет — `com.headswap.local.carbridge.profile`.
3. Для проверки музыки разрешите в карточке профиля показывать текущий трек и управлять воспроизведением. Без доступа панель может работать с остальными функциями. Если нет активного плеера, карточка не выдаёт тестовую песню за настоящую.
4. Подключите ГУ CarLife. В каталоге профиля выберите обычное приложение или навигатор. Проверьте «Назад», домашний экран, открытие и закрытие музыкальной панели, перемещение её на другую сторону. Изменение ширины должно сохранять текущую задачу карты; кнопки нижней панели должны реагировать независимо от карты. Сворачивая карту для показа меню профиля, проверьте возврат к запущенному приложению.
5. Остановите сеанс, выберите обычный Android Desktop и подключитесь снова. Должны появиться прежние каталог и боковая панель. Плотность основного дисплея телефона должна оставаться исходной.

## Разработчику

Поставьте `HeadSwap-Profile-Example.apk` для примера обычного внешнего профиля. Отдельный пример музыкальной панели HeadSwap использует идентификатор `headswap-music-example`. Оба примера можно собрать из SDK ZIP без исходников хоста. Авторский APK независимо выбирает внешний вид, подпись, каталог, кнопки и содержимое профиля. [SDK](../sdk/desktop-panel-v1/README.md) · [Пример проекта](../examples/android-desktop-panel/README.md).

Для собственного полноэкранного UI объявите логические метки `DASHBOARD` и `PROFILE_CHROME` на Activity профиля. HeadSwap передаст ей временный сеанс. Профиль может показать своё меню над картой, исключить из области карты свой док и запросить запуск выбранного приложения. Микрофон и голосовой канал в API v1 зарезервированы раздельно.

## Сборка

Требуются JDK 17 и Android SDK 37. Из корня репозитория выполните

```sh
./android/gradlew -p android :app:assembleDebug :app:testDebugUnitTest :app:assembleDebugAndroidTest
./android/gradlew -p sdk/desktop-panel-v1 assembleRelease testDebugUnitTest
```

Для Windows используйте `android\gradlew.bat`. Исходники CarBridge и ключ автора для сборки хоста и SDK не требуются.
