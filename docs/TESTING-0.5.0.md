# Проверка HeadSwap Desktop 0.5.0-dev

Это локальная сборка для разработки. Публичная стабильная версия остаётся 0.4.1. В составе тестового комплекта есть APK HeadSwap (код 36), библиотека SDK v1 в формате AAR и два необязательных APK демонстрационных профилей. Для независимых профилей достаточно основного приложения. DriveDeck можно проверять с прежним совместимым компонентом code305.

## Что выбрать на главном экране

1. На **тестовом** устройстве Android 13+ установите `HeadSwap-Desktop-0.5.0-dev.apk` обычным установщиком. Установка поверх официального 0.4.1 с тем же сертификатом сохраняет данные. При использовании ADB подставьте идентификатор именно тестового устройства.
2. Установите `CarBridge-Profile-Test-Adapter.apk`, если хотите проверить именованный профиль CarBridge. Это независимо подписанный тестовый адаптер из данного проекта, с явно указанным тестовым именем. Самостоятельный CarBridge Offline v0.43 не предоставляет этот интерфейс. Для отдельного произвольного профиля установите `HeadSwap-Profile-Example.apk`.
3. Пока нет активной проекции, на **главном экране** нажмите **«Профиль» → «CarBridge»** или выберите демонстрационную панель. Проверьте пакет, класс, версию и отпечаток сертификата и нажмите **«Использовать»**. Без совместимого пакета строка CarBridge объясняет, что требуется установить. При нескольких претендентах можно выбрать точную Activity. В «Компонентах» также доступен перечень установленных независимых профилей.
4. Активируйте доступ обычным способом и подключите CarLife по USB. Родительский экран, боковая панель и кнопки «Домой» и «Назад» должны принадлежать HeadSwap. Интерфейс автора отображается в отдельной рабочей области. Проверьте собственные элементы 70/30, смену стороны и выбор приложения из сетки лаунчера. «Каталог HeadSwap» и «Домой» возвращают штатный каталог. Из него можно снова открыть выбранную панель.
5. Завершите соединение. На главном экране можно выбрать встроенный Android Desktop, DriveDeck или поддерживаемый Samsung DeX. Удаление тестового APK не должно блокировать штатный Android Desktop.

```sh
adb -s "$SERIAL" install -r HeadSwap-Desktop-0.5.0-dev.apk
adb -s "$SERIAL" install -r CarBridge-Profile-Test-Adapter.apk
adb -s "$SERIAL" install -r HeadSwap-Profile-Example.apk
```

## Автору профиля

Соберите APK с собственным `applicationId`, подписью и настроенным входом Activity. Объявите API major 1 и внутренний профиль `android-desktop`. Для именованной строки CarBridge нужен `MODE_ID=carbridge`. Присвоение имени не предоставляет доверия к сертификату. Автор может обновлять свою Activity, сетку, раскладку, предпочтения и обработчики без изменения ключа HeadSwap. Системный установщик Android обновляет именно APK автора. [Подключение AAR и публичные операции](../sdk/desktop-panel-v1/README.md) · [Пример двух профилей](../examples/android-desktop-panel/README.md).

В этой сборке клиент может запросить открытие обычной программы или возврат к каталогу. Интерфейс профиля остаётся обычным Android-интерфейсом, дополнительные собственные функции пишет автор. Размещение чужого приложения и музыкального виджета хоста в одной композиции, общий каталог загрузок, микрофон и голосовой канал не объявляются рабочими возможностями этой версии. [Проект следующего этапа](DESKTOP-COMPONENT-API.md).

## Воспроизвести сборку

Из корня репозитория с JDK 17 и Android SDK 37 выполните:

```sh
./android/gradlew -p android :app:assembleDebug :app:testDebugUnitTest :app:assembleDebugAndroidTest
./android/gradlew -p sdk/desktop-panel-v1 assembleRelease testDebugUnitTest
```

Для Windows используйте `android\gradlew.bat`. Исходный код CarBridge и его ключ для этих команд не требуются. Для установки поверх существующего HeadSwap нужна совместимая подпись. При самостоятельной отладке используйте отдельное тестовое устройство или Android-пользователя с вашей сборкой.
