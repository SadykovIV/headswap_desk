# HeadSwap Desktop 0.6.13

Изменения с 0.6.3:

- **Звук и видео CarLife синхронизируются по времени захвата и отправки.** При замедлении соединения HeadSwap пропускает устаревшее видео и возвращается к свежему ключевому кадру. Если сама магнитола задерживает картинку, можно настроить отдельную поправку для её модели.
- **Первый запуск — три шага:** компоненты, разрешения и активация. Доступы HeadSwap и DriveDeck видны отдельно. На последнем шаге можно активировать приложение по Wi-Fi, через Shizuku или с компьютера и сразу завершить настройку.
- **Надёжнее активация и восстановление рабочего стола.** Исправлены ввод кода в приложении, ответ из уведомления и повторная проверка доступа после переподключения.
- **Названия улиц на приборной панели и HUD** включаются отдельно. Для совместимых магнитол длинные названия сокращаются; также обновлена передача миниатюр обложек.
- **Управление экраном телефона** вынесено в отдельный пункт. В настройках убраны дублирующие переходы, справка открывается по небольшому значку ⓘ.

Обновите HeadSwap поверх установленной версии и повторно активируйте доступ. Если DriveDeck **0.6.9 (334)** уже установлен, обновлять его не нужно.
