# Установка и активация HeadSwap Desktop

Для установки нужны телефон с Android 13 или новее, Wi-Fi на время активации и USB-кабель с передачей данных. Магнитола должна поддерживать Baidu CarLife по USB. Установку и настройку выполняйте на телефоне.

## 1. Установите приложения

1. Для профиля **DriveDeck** скачайте на телефон `DriveDeck-HeadSwap-0.6.7-code263.apk` и `HeadSwap-Desktop-0.2.13-experimental.apk` из одного выпуска. Сначала установите DriveDeck, затем HeadSwap Desktop. Если Android спросит, разрешите браузеру или файловому менеджеру устанавливать приложения из этого источника. [Файлы выпуска 0.2.13](https://github.com/SadykovIV/headswap_desk/releases/tag/v0.2.13)
2. Откройте HeadSwap Desktop, разрешите уведомления при запросе и выберите профиль **DriveDeck**. Для профиля **Android Desktop** достаточно одного APK HeadSwap. На совместимых Samsung доступен также профиль **Samsung DeX**, для которого нужен запущенный Shizuku.
3. Для Android Desktop и DriveDeck в **Дополнительно** по умолчанию выбран **Доступ HeadSwap — без Shizuku**. На новой установке уже отмечены **«Передавать звук по USB»** и **«Управление экраном телефона»**. Оставьте их включёнными для музыки и подсказок через магнитолу и гашения панели по таймеру. Если нужна только одна функция, снимите другую отметку перед активацией. При обновлении сохранённые настройки имеют приоритет.

Если вы собираете DriveDeck самостоятельно, используйте оригинальный APK code258 и патчи к нему. Обе части комплекта должны быть подписаны одним ключом. [Сборка адаптированного DriveDeck](https://github.com/SadykovIV/headswap_desk/blob/main/BUILDING.md#дополнительный-профиль-drivedeck)

## 2. Активируйте доступ на телефоне

1. Подключите телефон к сети Wi-Fi. В настройках Android включите **Параметры разработчика → Беспроводная отладка**. На Samsung меню разработчика открывается после семи нажатий на **Номер сборки** в разделе **Сведения о телефоне → Сведения о ПО**.
2. В разделе **Доступ HeadSwap** нажмите **Активировать с телефона**. При запросе Android разрешите HeadSwap доступ к локальной сети. При первом запуске откройте настройки беспроводной отладки и выберите **Подключить устройство с помощью кода сопряжения**. Оставьте окно кода открытым рядом с HeadSwap в режиме разделённого экрана. Введите шесть цифр в HeadSwap и нажмите **Сопрячь и активировать**.
3. После перезапуска HeadSwap дождитесь надписи **Доступ HeadSwap активен** или **Готов к автоматическому подключению**. Теперь Wi-Fi можно отключить. Для добавления опции после активации остановите сеанс, включите опцию в **Дополнительно**, нажмите **Завершить доступ и закрыть HeadSwap** и повторите активацию с телефона.

## 3. Подключите автомобиль

Разблокируйте телефон, откройте **Baidu CarLife** на ГУ и подключите кабель. При первом подключении подтвердите доступ HeadSwap к USB-аксессуару на телефоне. Если сеанс остановлен, нажмите **Подключить**. Когда появится рабочий стол, откройте приложение касанием на ГУ.

После обычного отсоединения кабеля повторная активация не требуется. После перезагрузки телефона, обновления или принудительной остановки HeadSwap активируйте доступ снова. Код нужен только при утрате прежнего сопряжения.

## Активация с компьютера через USB

Для Android Desktop и DriveDeck можно активировать доступ с компьютера. Установите приложения из шага 1, включите на телефоне **Отладку по USB**, подключите телефон к компьютеру и подтвердите доверие к нему. Распакуйте Android SDK Platform-Tools и откройте терминал внутри каталога `platform-tools`. [Android SDK Platform-Tools](https://developer.android.com/tools/releases/platform-tools)

В Windows используйте **cmd.exe**. Первая команда должна показать один телефон со статусом `device`.

```bat
adb.exe devices -l
adb.exe -d shell "CLASSPATH=$(pm path com.headswap.desk | cut -d: -f2 | head -n 1) app_process / com.headswap.desk.dex.ManualAccessLauncher --audio --screen"
```

В терминале macOS или Linux сохраните одинарные кавычки.

```sh
./adb devices -l
./adb -d shell 'CLASSPATH=$(pm path com.headswap.desk | cut -d: -f2 | head -n 1) app_process / com.headswap.desk.dex.ManualAccessLauncher --audio --screen'
```

`--audio` разрешает передачу воспроизводимого звука по USB, `--screen` разрешает управление панелью и чтение времени активности экрана для таймера. Уберите параметр той функции, которую вы отключили в приложении. Команда без обоих параметров даёт базовый доступ к рабочему столу и управлению плеером. При успехе в терминале появится `HEADSWAP_READY`.

## Проверка с эмулятором на Mac

У **HeadSwap Private HU** по умолчанию установлен лимит 180 секунд на один тестовый сеанс. По таймеру приёмник отправляет `PAUSE_MEDIA` и `VIDEO_PAUSE`, затем закрывает соединение. Это происходит и при рабочем видео и касаниях. Для десятиминутной проверки запустите Private HU с параметром `--session-seconds 600`. Для более длительного теста используйте **CarLife HeadUnit Emulator**.

Если отключение произошло раньше и журнал показывает ошибку чтения или записи USB, проверьте кабель с передачей данных и USB-порт. Таймер Private HU объясняет только штатное завершение его тестового сеанса.

## Настройки экрана и обновления

- Во время работы CarLife физическая панель по умолчанию гаснет через 10 секунд бездействия телефона. Двойное касание возвращает предыдущее приложение. Поддержка физического выключения зависит от прошивки. Если активация сообщает, что управление панелью недоступно, снимите эту отметку и повторите активацию.
- Для передачи через CarLife HeadSwap захватывает воспроизводимый звук телефона. Доступность звука звонков и защищённого контента зависит от устройства и приложения.
- Поверх 0.2.10–0.2.12 с той же подписью установите новый HeadSwap и активируйте его снова. Совместимый **DriveDeck · HeadSwap** code263 можно оставить. Для следующих обновлений DriveDeck используйте адаптированный APK из выпуска HeadSwap. Для перехода с версий до 0.2.10 завершите доступ в старом HeadSwap, установите новый пакет, настройте его и после проверки отключите старую копию.
