# Установка и активация HeadSwap Desktop

Для предварительной версии скачайте [HeadSwap-Desktop-0.5.0.apk](https://github.com/SadykovIV/headswap_desk/releases/download/v0.5.0/HeadSwap-Desktop-0.5.0.apk), установите поверх прежней версии и снова активируйте доступ. Для DriveDeck подходит версия 0.6.8 code305. [Настройка независимых профилей](docs/TESTING-0.5.0.md). Ниже приведён также порядок установки стабильной 0.4.1.

Для установки нужны телефон с Android 13 или новее, Wi-Fi на время активации и USB-кабель с передачей данных. Магнитола должна поддерживать Baidu CarLife по USB. Установку и настройку выполняйте на телефоне.

## 1. Установите приложения

1. Установите на телефон `HeadSwap-Desktop-0.4.1-experimental.apk`. Если Android спросит, разрешите установку браузеру или файловому менеджеру, в котором вы открыли файл. [Опубликованные выпуски](https://github.com/SadykovIV/headswap_desk/releases)
2. Откройте HeadSwap, разрешите уведомления и выберите профиль. Для **Android Desktop** достаточно одного APK. Для **DriveDeck** откройте **Настройки → Компоненты HeadSwap Desktop → Установить из файла…**, выберите `DriveDeck-HeadSwap-0.6.8-code305.apk` из комплекта и подтвердите установку. В **Компонентах HeadSwap Desktop** представлены основное приложение и DriveDeck. В каждой карточке доступна проверка обновлений. Профиль **Samsung DeX** доступен на совместимых телефонах Samsung. В разделе «Активация» выберите Shizuku или встроенный ADB. Для ADB в этом профиле есть отдельное сопряжение.
3. На главном экране в разделе **Активация** оставьте **Доступ HeadSwap** для Android Desktop или DriveDeck. При необходимости там можно выбрать Shizuku. В **Настройки → Звук** и **Настройки → Экран телефона** выберите, нужны ли передача звука по USB и управление панелью. На новой установке оба переключателя включены. После выбора вернитесь на главный экран для активации.

**Если Google Play Защита заблокировала установку.** В некоторых регионах Google блокирует установку из браузера или файлового менеджера, когда APK объявляет службу доступа к уведомлениям. HeadSwap использует эту службу для навигационных подсказок. Служба специальных возможностей удалена из версии 0.3.4. При сообщении о риске финансового мошенничества оставьте защиту включённой и сообщите разработчику версию APK и точный текст предупреждения. [Пояснение Google](https://developers.google.com/android/play-protect/warning-dev-guidance#app-blocked-to-protect-your-device)

Если вы собираете DriveDeck самостоятельно, используйте оригинальный APK 0.6.8 code300 и исходные патчи из комплекта. Команды сборки приведены в README архива патчей. Оба приложения нужно подписать одним ключом. [Оригинальный DriveDeck 0.6.8 code300](https://github.com/RotkivKiv/DriveDeck-Updates/releases/tag/stable-code300)

## 2. Активируйте доступ на телефоне

1. Подключите телефон к сети Wi-Fi. В настройках Android включите **Параметры разработчика → Беспроводная отладка**. На Samsung меню разработчика открывается после семи нажатий на **Номер сборки** в разделе **Сведения о телефоне → Сведения о ПО**.
2. В разделе **Доступ HeadSwap** нажмите **Активировать с телефона**. На Android 17 при запросе разрешите HeadSwap доступ к локальной сети для поиска службы беспроводной отладки. При первом запуске откройте настройки беспроводной отладки и выберите **Подключить устройство с помощью кода сопряжения**. Оставьте окно кода открытым рядом с HeadSwap в режиме разделённого экрана. Введите шесть цифр в HeadSwap и нажмите **Сопрячь и активировать**.
3. После перезапуска HeadSwap дождитесь надписи **Доступ HeadSwap активен** или **Готов к автоматическому подключению**. Теперь Wi-Fi можно отключить. Для добавления опции после активации остановите сеанс, включите опцию в **Настройках**, вернитесь на главный экран и нажмите **Завершить доступ и закрыть HeadSwap** и повторите активацию с телефона.

## 3. Подключите автомобиль

Разблокируйте телефон, откройте **Baidu CarLife** на ГУ и подключите кабель. При первом подключении подтвердите доступ HeadSwap к USB-аксессуару на телефоне. Если сеанс остановлен, нажмите **Подключить**. Когда появится рабочий стол, откройте приложение касанием на ГУ.

В профиле **Android Desktop** слева находится ваша панель приложений. Чтобы добавить приложение, удерживайте его в каталоге, перетащите на панель и отпустите. Можно также удержать карточку, отпустить на месте и выбрать **Закрепить на панели**. Чтобы убрать ярлык, удерживайте его на панели и нажмите корзину. Само приложение остаётся в каталоге и на телефоне. Выбор сохраняется при отключении USB и перезапуске HeadSwap.

**Назад** возвращает на предыдущий экран открытого приложения, **Домой** открывает каталог магнитолы. Панель доступна только в профиле Android Desktop.

После обычного отсоединения кабеля повторная активация не требуется. После перезагрузки телефона, обновления или принудительной остановки HeadSwap активируйте доступ снова. Код нужен только при утрате прежнего сопряжения.

## Активация с компьютера через USB

Для Android Desktop и DriveDeck можно активировать доступ с компьютера. Установите приложения из шага 1, включите на телефоне **Отладку по USB**, подключите телефон к компьютеру и подтвердите доверие к нему. Распакуйте Android SDK Platform-Tools и откройте терминал внутри каталога `platform-tools`. [Android SDK Platform-Tools](https://developer.android.com/tools/releases/platform-tools)

В Windows используйте **cmd.exe**. Первая команда должна показать один телефон со статусом `device`.

```bat
adb.exe devices -l
adb.exe -d shell "CLASSPATH=$(pm path com.headswap.desk | cut -d: -f2 | head -n 1) app_process / com.headswap.desk.dex.ManualAccessLauncher --audio --screen"
```

В терминале macOS или Linux сохраните одинарные кавычки.

```sh
./adb devices -l
./adb -d shell 'CLASSPATH=$(pm path com.headswap.desk | cut -d: -f2 | head -n 1) app_process / com.headswap.desk.dex.ManualAccessLauncher --audio --screen'
```

`--audio` разрешает передачу воспроизводимого звука по USB, `--screen` разрешает управление панелью и чтение времени активности экрана для таймера. Уберите параметр той функции, которую вы отключили в приложении. Команда без обоих параметров даёт базовый доступ к рабочему столу и управлению плеером. При успехе в терминале появится `HEADSWAP_READY`.

## Проверка с эмулятором на Mac

У **HeadSwap Private HU** по умолчанию установлен лимит 180 секунд на один тестовый сеанс. По таймеру приёмник отправляет `PAUSE_MEDIA` и `VIDEO_PAUSE`, затем закрывает соединение. Это происходит и при рабочем видео и касаниях. Для десятиминутной проверки запустите Private HU с параметром `--session-seconds 600`. Для более длительного теста используйте **CarLife HeadUnit Emulator**.

Если отключение произошло раньше и журнал показывает ошибку чтения или записи USB, проверьте кабель с передачей данных и USB-порт. Таймер Private HU объясняет только штатное завершение его тестового сеанса.

## Настройки экрана и обновления

HeadSwap устанавливается поверх предыдущей версии. После обновления HeadSwap нажмите **Активировать с телефона**. Если сопряжение сохранилось, повторно вводить код не потребуется. Сам HeadSwap проверяет обновления через **Настройки → Приложение → Проверить обновления HeadSwap Desktop**.

**DriveDeck обновляется отдельно:** остановите сеанс DriveDeck, откройте **Настройки → Компоненты HeadSwap Desktop**, нажмите **Проверить обновления** и выберите предложенную версию. Если Android спросит, разрешите установку из источника HeadSwap и вернитесь к установщику. Для установки заранее скачанного файла интернет не нужен. HeadSwap проверяет пакет, подпись и номер сборки; при скачивании из каталога — также размер и SHA-256. Обычный APK DriveDeck из канала автора сюда не подходит. Не удаляйте прежнюю версию: при обновлении поверх неё Android сохраняет данные и настройки.

- **Экран телефона.** Включите **Управление экраном телефона**, затем откройте **Способ отключения**. **Выключать экран** отключает питание панели во время USB-проекции. **Затемнять экран** показывает чёрное окно HeadSwap с минимальной яркостью. Для затемнения оставьте HeadSwap открытым на телефоне. Двойное касание возвращает изображение. В **Гасить через** доступны 10 секунд, системный интервал и **Без таймера**. При выключенном таймере ручная кнопка по-прежнему применяет выбранный способ.
- **Если панель недоступна.** Рабочий стол продолжит работу без таймера. При активации с компьютера об этом сообщает строка `HEADSWAP_PANEL_UNAVAILABLE` перед `HEADSWAP_READY`.
- **Звук.** Включите **Передавать звук по USB** перед активацией и выберите источник **CarLife** на магнитоле. HeadSwap передаёт музыку и навигационные подсказки. Для звонков можно оставить подключение по Bluetooth.
- **Диагностика.** Для обращения в поддержку отправьте ZIP-отчёт из HeadSwap. Новые журналы называются `HeadSwapDesk-ГГГГММДД-ЧЧММСС.log` и содержат результат активации. Предыдущие журналы `headswap-*.log` также доступны.
- Для перехода с версий до 0.2.10 завершите доступ в старом HeadSwap, установите новый пакет, настройте его и после проверки отключите старую копию.


**HONOR ABR-LX1.** На этой модели аппаратное выключение панели может погасить и экран ГУ. По умолчанию выбран вариант **Затемнять экран**. Явный выбор одного из двух способов сохраняется.

При выключении «Управление экраном телефона» дочерние параметры таймера скрываются. Выбранный ранее интервал сохраняется при повторном включении.

## Масштаб карт и кнопки DriveDeck

Выбранный DPI относится к виртуальному рабочему столу магнитолы. Основной дисплей телефона сохраняет свой системный масштаб на всём протяжении сеанса.

При первом запуске выбраны **1280 × 720, 15 кадров/с и 128 DPI**. При обновлении явно выбранные значения сохраняются.

Чтобы настроить масштаб, остановите сеанс и откройте в HeadSwap **Настройки → Изображение на магнитоле → Размер интерфейса**. Выберите конкретный DPI или «Авто». Значение применяется при следующем подключении и относится к дисплею магнитолы. «Авто» учитывает высоту изображения.

Откройте **Настройки → Изображение на магнитоле → Исправить DPI приложения**. В списке уже есть Яндекс Карты и Яндекс Навигатор. Нажмите **Добавить приложение**, найдите его по названию или пакету и выберите. Кнопка удаления рядом со строкой исключает приложение из списка. Выключатель на этом экране приостанавливает коррекцию, сохраняя список. Изменения применяются при следующем подключении Android Desktop или DriveDeck.

Для выбранных приложений HeadSwap увеличивает разрешение и DPI внутреннего буфера в одной пропорции, затем выводит изображение в исходном размере окна. Элементы, нарисованные в фиксированных пикселях, становятся мельче, кнопки в dp сохраняют размер. Для произвольного списка в DriveDeck установите **code305** из комплекта. Если Карты открыли маршрут в отдельном Навигаторе в том же окне, HeadSwap сохраняет Навигатор при восстановлении панели.

Чтобы открыть системные «Настройки» Android на магнитоле, выберите их значок в меню приложений DriveDeck. Для отдельной команды «Системные настройки» в самом DriveDeck обновите его до code304. Экран «Настройки» в приложении HeadSwap на телефоне служит для параметров HeadSwap.

Для полноэкранного запуска одиночного ярлыка из дока включите в DriveDeck **Настройки → Главный экран → Дополнительные параметры → Одиночные приложения из дока — на весь экран**. При открытии пары приложений остаются два встроенных окна и обычный док.

В **DriveDeck → Настройки → Док → Поведение дока** отдельно включаются **Назад в полноэкранных приложениях** и **Домой в полноэкранных приложениях**. Откройте приложение в полноэкранном режиме из DriveDeck. Приложение занимает весь экран. Круглая кнопка «Домой» появляется поверх него в левом нижнем углу и возвращает в DriveDeck на магнитоле. Если выбраны обе кнопки, «Назад» находится над «Домой» и возвращает на предыдущий экран приложения. Оба переключателя изначально выключены.

Эти кнопки применяются к обычному запуску приложения из DriveDeck. Ссылки, открывающие сразу маршрут или файл, и системные диалоги обрабатываются Android обычным способом. В **Samsung DeX** выбранный DPI применяется к внешнему рабочему столу. Буфер отдельных нативных окон принадлежит DeX. Настройка уменьшения знаков доступна в Android Desktop и DriveDeck.

## Клавиатура и приборная панель

**Ввод на магнитоле.** Коснитесь поля поиска. Штатная клавиатура телефона появится в этом окне, даже если HeadSwap погасил панель телефона. Нажмите «Назад» на магнитоле один раз, чтобы скрыть клавиатуру и остаться в поиске. Для ввода и кнопки «Назад» специальные возможности не нужны. В 0.5.0 после обновления APK снова активируйте доступ. Если действующий сеанс потерял службу клавиатуры, повторная обычная активация может восстановить её для открытых окон. После восстановления коснитесь поля поиска ещё раз.

**Песня.** Запустите плеер, который публикует название и исполнителя через Android. В режиме «Доступ HeadSwap» данные поступают из активной медиасессии. В режиме Shizuku для чтения медиасессии может потребоваться доступ HeadSwap к уведомлениям.

**Ближайший манёвр.** Включите **Настройки → Приборная панель и HUD → Подсказки навигации на приборной панели и HUD**, предоставьте доступ к уведомлениям и начните ведение в Яндекс Навигаторе или Картах. На Android 16 и новее HeadSwap также читает стрелку и расстояние из видимой карточки ближайшего манёвра в собственном окне Android Desktop или DriveDeck. Для фонового ведения и более ранних версий Android используются навигационные уведомления. На магнитоле или в эмуляторе должна быть активна подписка на навигацию. [Фоновые подсказки Яндекс Навигатора](https://yandex.ru/support/navigator/ru/route-hints)
