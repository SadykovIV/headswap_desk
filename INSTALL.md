# Установка и первый запуск

HeadSwap Desktop 0.2.12 устанавливается **на телефон**. Для вывода изображения нужны Android 13 или новее, головное устройство (ГУ) с Baidu CarLife по USB и USB-кабель с передачей данных. Проверьте, какой USB-порт автомобиля предназначен для CarLife. Настройку выполните на стоянке.

## 1. Установите APK и выберите рабочий стол

1. Скачайте `HeadSwap-Desktop-0.2.12-experimental.apk` из выпуска. Откройте файл на телефоне. Если Android запросит разрешение на установку из этого источника, разрешите его файловому менеджеру или браузеру, через который открываете APK. [Файлы выпуска](https://github.com/SadykovIV/headswap_desk/releases/tag/v0.2.12)
2. Запустите **HeadSwap Desktop** и при запросе разрешите уведомления. Выберите **Android Desktop**, чтобы открывать установленные на телефоне приложения на отдельном экране. Для этого профиля достаточно одного APK.
3. Для профиля **DriveDeck** нужен адаптированный пакет `ru.drivedeck.headswap`, code263. Уже установленная версия code263 из совместимого комплекта подходит. Для первой установки используйте готовый патч по шагам ниже. Если собираете приложения из исходников, подпишите HeadSwap и адаптацию DriveDeck одним ключом. [Исходные патчи и сборка](https://github.com/SadykovIV/headswap_desk/blob/main/BUILDING.md) · [Оригинал DriveDeck 0.6.7 code258](https://github.com/RotkivKiv/DriveDeck-Updates/releases/tag/stable-code258)
4. В **Дополнительно** выберите **Доступ HeadSwap — без Shizuku**. На новой установке он выбран по умолчанию. Если нужны звук по USB или управление экраном телефона, включите соответствующие опции перед активацией. Если настройки недоступны, сначала остановите подключение или ожидание.

### Как получить адаптированный DriveDeck

1. На компьютере скачайте файл `DriveDeck-0.6.7-code258.apk` из [выпуска автора](https://github.com/RotkivKiv/DriveDeck-Updates/releases/tag/stable-code258) и архив `DriveDeck-0.6.7-code258-to-HeadSwap-code263-patch.zip` из [выпуска HeadSwap Desktop](https://github.com/SadykovIV/headswap_desk/releases/tag/v0.2.12).
2. Распакуйте архив. Поместите оригинальный APK рядом с `apply_patch.py`, откройте терминал в этой папке и выполните команду для своей ОС. Нужен Python 3.9 или новее.

   Windows:
   ```bat
   py -3 apply_patch.py "DriveDeck-0.6.7-code258.apk"
   ```

   macOS или Linux:
   ```sh
   python3 apply_patch.py "DriveDeck-0.6.7-code258.apk"
   ```

3. Скрипт проверит исходный файл и результат. Установите полученный `DriveDeck-HeadSwap-0.6.7-code263.apk` **на телефон**, затем в HeadSwap выберите **DriveDeck**. Штатный APK из первого шага нужен только как вход для патча. Его установка на ГУ не требуется.

## 2. Активируйте доступ на телефоне

1. Подключите телефон к сети Wi-Fi. В настройках Android включите **Параметры разработчика → Беспроводная отладка**. На Samsung меню разработчика открывается после семи нажатий на **Номер сборки** в разделе **Сведения о телефоне → Сведения о ПО**.
2. В разделе **Доступ HeadSwap** нажмите **Активировать с телефона**. При первом запуске откройте настройки беспроводной отладки и выберите **Подключить устройство с помощью кода сопряжения**. Оставьте окно кода открытым рядом с HeadSwap в режиме разделённого экрана. Введите шесть цифр в HeadSwap и нажмите **Сопрячь и активировать**.
3. После перезапуска HeadSwap дождитесь надписи **Доступ HeadSwap активен** или **Готов к автоматическому подключению**. Теперь Wi-Fi можно отключить.

## 3. Подключите автомобиль

Разблокируйте телефон, откройте **Baidu CarLife** на ГУ и подключите кабель. При первом подключении подтвердите доступ HeadSwap к USB-аксессуару на телефоне. Если сеанс остановлен, нажмите **Подключить**. Когда появится рабочий стол, откройте приложение касанием на ГУ.

После обычного отсоединения кабеля повторная активация не требуется. После перезагрузки телефона, обновления или принудительной остановки HeadSwap активируйте доступ снова. Код нужен только при утрате прежнего сопряжения.

## Если беспроводная отладка недоступна

Для Android Desktop и DriveDeck можно активировать доступ с компьютера. Скачайте Android SDK Platform-Tools под свою ОС, распакуйте архив и откройте терминал **внутри каталога platform-tools**. Включите USB-отладку на телефоне, подключите его к компьютеру и подтвердите доверие к компьютеру на экране телефона. [Android SDK Platform-Tools](https://developer.android.com/tools/releases/platform-tools)

В Windows используйте **cmd.exe**. Первая команда должна показать один телефон со статусом `device`.

```bat
adb.exe devices -l
adb.exe -d shell "CLASSPATH=$(pm path com.headswap.desk | cut -d: -f2 | head -n 1) app_process / com.headswap.desk.dex.ManualAccessLauncher"
```

В терминале macOS или Linux сохраните одинарные кавычки.

```sh
./adb devices -l
./adb -d shell 'CLASSPATH=$(pm path com.headswap.desk | cut -d: -f2 | head -n 1) app_process / com.headswap.desk.dex.ManualAccessLauncher'
```

При необходимости добавьте `--audio` или `--screen` после `ManualAccessLauncher`, внутри кавычек. Соответствующая опция должна быть заранее включена в HeadSwap. Дождитесь `HEADSWAP_READY`, отсоедините телефон от компьютера и перейдите к шагу 3.

## Совместимость и обновление

- Физическое выключение панели и пробуждение двойным касанием зависят от прошивки телефона. Передача звука по USB включается отдельно. Доступность звука звонков, контента с DRM и вывода отдельных приложений зависит от устройства.
- **Samsung DeX** требует совместимого Samsung и запущенного Shizuku с предоставленным HeadSwap доступом. Для профилей Android Desktop и DriveDeck подходят способы активации выше.
- Поверх 0.2.10 или 0.2.11 из того же комплекта установите новый HeadSwap и повторите активацию. Совместимый DriveDeck code263 можно оставить. При переходе с 0.2.9 или более ранней версии завершите доступ в старом приложении, настройте новый пакет и после проверки отключите старую копию, чтобы она не перехватывала USB.
